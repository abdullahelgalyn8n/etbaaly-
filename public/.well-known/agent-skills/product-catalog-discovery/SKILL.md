# Product Catalog Discovery Skill

Use this skill to fetch products, categories, pricing guidelines, and available finishes.

## Endpoints

- API: `GET https://etbaaly.azagency.online/api/products`
- OpenAPI: `https://etbaaly.azagency.online/openapi.json`
- MCP Server: `https://etbaaly.azagency.online/api/mcp`
